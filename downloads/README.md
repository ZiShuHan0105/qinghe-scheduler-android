## 青禾排课

面向初高中学校的课程排班 App，支持：

- 按班级 / 教师查看课表
- 教师、班级、课程、教室和备注
- 早餐、午餐、晚餐、早自习、晚自习
- 课间操、眼保健操、课间运动
- 自定义课程和自定义时间段
- 冲突提醒
- PNG、ZIP、Excel、JSON 导出
