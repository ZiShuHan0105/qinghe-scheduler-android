# 十个原创工具 APK

这十个 APK 根据 Google Play 工具类常见高频功能组合设计，采用原创名称和界面，不复制第三方 App 的品牌、图标或专有布局。每个 APK 都是独立包名，可以单独安装。

| APK | 功能 |
|---|---|
| qinghe-qr-studio | 文本二维码内容预览工具 |
| qinghe-smart-calculator | 双数计算器 |
| qinghe-unit-converter | 米 / 英尺单位转换 |
| qinghe-screen-lamp | 全屏手电筒 / 屏幕灯 |
| qinghe-password-maker | 随机安全密码生成 |
| qinghe-stopwatch | 秒表、开始、暂停、重置 |
| qinghe-compass | 设备磁场传感器状态 |
| qinghe-notepad | 本地记事和保存 |
| qinghe-file-info | 系统文件选择和文件信息 |
| qinghe-bmi | BMI 健康指数计算 |

构建脚本会从 `ToolActivity.java.template` 生成十个独立 Android 工程并生成 APK。
